ALLUR DIGITAL TWIN — цифровой двойник завода (Костанай)
======================================================

ЗАПУСК
------
1) Установите Python 3.10–3.12 (https://www.python.org/downloads/, галочка "Add python.exe to PATH").
   Если Python уже есть — пропустите.

2) Дважды щёлкните  start.bat
   Первый запуск ставит библиотеки. Дальше сайт откроется сам:
       http://localhost:8000
   

   Остановить: Ctrl+C в чёрном окне.


TELEGRAM-БОТ (сейчас ВЫКЛЮЧЕН)
------------------------------
Код бота сохранён. Чтобы включить, в файле .env:
    BOT_ENABLED=1
    TELEGRAM_BOT_TOKEN=токен от @BotFather
    ADMIN_PIN=любой PIN
Дальше в Telegram: /admin ВАШ_PIN (станете администратором), получатели пишут боту /start, вы подтверждаете.
Управлять линией из Telegram может только администратор бота. Пока бот выключен, блок «Получатели отчётов»
в интерфейсе скрыт, при запуске ничего про бота не спрашивается и не печатается.



ВАЖНО
-----
* Для графиков и 3D сайту нужен интернет (библиотеки грузятся с CDN).
* Файл .env содержит секреты — не пересылайте его вместе с папкой (в архив кладите только .env.example).
* 3D-линия рассчитана на обычный офисный ПК: простые формы, без теней, ограничение разрешения.
  В Настройках можно выключить подписи и анимации, если компьютер слабый.
